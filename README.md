# Odd Integer Guessing Game

A simple Python game where the player guesses an odd integer between 1 and 1000.

## Project Structure

```
GuessingGame/
├── src/
│   ├── __init__.py
│   └── guessing_game.py
├── tests/
│   ├── __init__.py
│   └── test_guessing_game.py
├── README.md
├── .gitignore
└── requirements.txt
```

## Running Tests

Run the tests using Python's unittest framework:

```bash
python -m unittest discover tests
```

Or run the test file directly:

```bash
python tests/test_guessing_game.py
```

## Development

This project is developed using Test-Driven Development (TDD).
